## 📌 Project Overview

A fully interactive Power BI sales dashboard built to replicate a real commercial ops reporting environment. Enables self-serve analysis across regions, products, and time periods — eliminating manual report generation.

---

## 🎯 Objective

Design and build a production-quality Power BI dashboard that tracks sales KPIs, enables drill-down analysis, and empowers non-technical stakeholders to answer their own business questions without analyst intervention.

---

## 📊 Dataset

| Detail | Info |
|--------|------|
| Records | 10,000+ |
| Type | Sales transactions |
| Key Fields | region, product, revenue, order_date, brand, quantity, discount |

---

## 📐 Dashboard Features

### KPIs Tracked (6+)
| KPI | Description |
|-----|-------------|
| Total Revenue | Sum of sales across all periods |
| Revenue Growth % | MoM and YoY growth rate |
| Regional Share | % revenue contribution by territory |
| Top Products | Ranked by revenue and volume |
| Average Order Value | Mean transaction size |
| Sales Velocity | Orders per time period |

### Interactivity
- **Dynamic slicers** — filter by brand, region, product category, and date range
- **Drill-down views** — Region → City → Product → SKU level
- **Cross-filtering** — clicking any visual filters all others on the page
- **Tooltips** — hover for additional context on every data point

---

## 🛠️ Technical Implementation

```
Data Model    →  Star schema with fact + dimension tables
DAX Measures  →  CALCULATE, SUMX, DIVIDE, RANKX, time-intelligence (SAMEPERIODLASTYEAR)
Power Query   →  Data cleaning, merging, type enforcement, column transformations
Visuals Used  →  Bar charts, line charts, KPI cards, map visual, matrix table, slicers
```

---

## 💡 Key Insights

- **Top 3 regions** contributed 61% of total revenue — flagged for resource concentration risk
- Products with **>15% discount** showed diminishing revenue returns — recommended pricing review
- **Q3** consistently underperformed — identified as opportunity for promotional campaigns
- Dashboard adoption reduced **ad-hoc report requests by ~30%** across commercial ops

---

## 📈 Business Impact

> This dashboard directly replicates the **self-serve BI workflow** used in enterprise sales ops and commercial analytics teams. The DAX measures and data model are portable to any sales dataset.
