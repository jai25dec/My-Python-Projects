### 1. SQL Bookstore Sales & Customer Analytics

[![SQL](https://img.shields.io/badge/MySQL-Advanced-4479A1?style=flat-square&logo=mysql&logoColor=white)](https://github.com/jai25dec/My-Python-Projects/tree/main/sql-bookstore)

**Domain:** Retail · Customer Analytics · Revenue Reporting

**Objective:** Analyse bookstore sales data using relational database design and advanced SQL to uncover revenue drivers and customer behaviour patterns.

**Key Work:**
- Designed a **3-table relational database** (books, customers, orders) with proper primary/foreign key relationships
- Wrote **10+ advanced SQL queries** using JOINs, Window Functions, Subqueries, and Aggregations
- Performed **customer segmentation** — identified the top 20% of customers contributing the most revenue (Pareto Analysis)
- Tracked **monthly sales trends** to support territory-level account planning

**Business Impact:**
> Enabled data-driven territory strategy by identifying high-value customer segments — directly applicable to CRM and sales ops reporting.

**Skills Demonstrated:** `Relational DB Design` `JOINs` `Window Functions` `Subqueries` `Aggregations` `Customer Segmentation` `Revenue Analysis`

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone https://github.com/jai25dec/My-Python-Projects.git
cd My-Python-Projects

# 2. Install dependencies
pip install pandas numpy matplotlib seaborn jupyter

# 3. Navigate to any project folder
cd spotify-data-analysis   # or any other project

# 4. Launch Jupyter Notebook
jupyter notebook
```

> For the SQL project, import the `.sql` file into MySQL Workbench and run the queries in sequence.
> For the Power BI project, open the `.pbix` file in Power BI Desktop.
